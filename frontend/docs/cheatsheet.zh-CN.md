# Free SSL 证书管理器使用文档

本文介绍云账号配置、DNS 管理、证书申请、自动部署、周期计划、邮件提醒和配置迁移。证书申请与同步支持腾讯云和阿里云；管理员负责配置和操作，只读用户负责查看。

## 快速开始

1. 首次打开平台时，使用初始化页面创建管理员账号。
2. 在“配置管理”新增云账号，启用需要的证书和 DNS 用途，并测试连接。
3. 在“域名管理”同步托管域名，在“SSL 证书管理”同步已有证书或申请新证书。
4. 需要自动部署时，先配置并测试“部署目标”，再从证书列表部署；周期申请与部署在“计划任务”中设置。
5. 在“邮件管理”配置 SMTP 和到期提醒。首页仪表盘可查看资源总量、状态分布和近期到期证书。

## 配置云平台账号

进入“配置管理”，点击新增或编辑：

- 选择腾讯云或阿里云，填写 AccessKey/Secret。
- 使用“用于证书管理”控制该账号是否参与证书同步和申请。
- 使用“用于 DNS 管理”控制该账号是否参与 DNS 托管域名和解析记录同步。
- 读取配置默认只显示密钥掩码；编辑时密钥留空保留原值。需要核对时使用查看密钥入口，关闭后隐藏原始值。
- 点击“测试连接”检查密钥权限和额度。测试结果会记录在“最近检测”列。
- 阿里云账号填写密钥后可以同步联系人，选择联系人保存后，申请证书会自动带入联系人；页面提供联系人控制台和 ListContact 文档链接。
- 配置可启用自动同步，选择分钟、小时、天或月，并设置本地执行时间。启用的用途决定同步域名或证书，执行记录可在审计日志查看。

按实际用途授予证书查询、申请、吊销、下载以及 DNS 域名和解析记录的读写权限。阿里云免费证书申请使用 CAS V2 接口；申请前需在云控制台领取并确认可用免费实例。免费额度、证书有效期与接口能力以云平台实际返回为准。

## 域名管理

进入“域名管理”后点击同步，平台会从已启用 DNS 管理的账号完整抓取托管域名。同步完成后：

- 点击域名行展开解析记录子表，不需要弹窗。
- 可以新增、编辑、启用、停用和删除解析记录。
- 证书自动 DNS 验证创建的记录会标记来源；是否自动清理由申请设置决定。
- 云端分页不稳定时，平台会重试并校验完整快照，避免用不完整结果覆盖本地数据。

## SSL 证书管理

进入“SSL 证书管理”：

- 同步已有云证书，或点击申请证书，选择已启用且用于证书管理的账号。
- 绑定域名由“前缀文本框 + 域名后缀下拉/手填”组成；根域名前缀留空。当前免费申请仅支持单个域名，不支持泛域名，不要填写协议或路径。
- 阿里云必须选择当前账号已领取、免费规格且尚未绑定域名的 V2 实例，并配置申请联系人。
- 验证方式可选云平台原生自动 DNS、本平台托管 DNS、手动 DNS 或文件验证。本平台托管 DNS 使用同一申请账号下已同步且能够覆盖申请域名的托管域，需先启用该账号 DNS 管理并同步域名。
- 手动 DNS 和文件验证按证书详情中的记录或路径、内容自行配置。自动 DNS 可选择签发成功后清理，仅删除本次创建且仍与验证快照匹配的记录；清理失败可在详情中重试。
- 提交后在列表或详情查看状态。结果待核对时先同步查询，避免重复申请占用额度。
- 可按状态筛选、查看详情、下载、吊销、取消审核和删除；具体操作受当前状态及云平台能力限制，已过期、已吊销和已取消证书支持批量清理。
- 下载时选择 Nginx、IIS、Apache 等格式，文件名为“绑定域名-格式-YYYYMMDD.zip”。已签发证书可通过“部署”发送到一个或多个部署目标。

## 部署目标与部署记录

1. 在“部署目标”新建目标，按实际产品和版本选择可用执行器。目前提供雷池社区版 9.x、群晖 DSM 7.x、Linux SSH 和 Windows SSH；Windows WinRM 暂不可用，以页面可选项为准。
2. 填写地址、认证方式、凭据及目标配置。SSH 目标需核对主机指纹；编辑时已有凭据留空保留原值。
3. Linux 文件目标先选择已签发的源证书和下载格式，再将包内文件映射到远端绝对路径。可用远端文件浏览器选择位置，按需设置权限、属主及部署后的验证、刷新或重启命令。
4. 保存并启用目标后点击“测试连接”。测试只检查认证及可用能力，不上传证书，也不执行刷新或重启。
5. 在证书列表点击“部署”，选择目标并“生成部署计划”，核对证书指纹、覆盖文件、关联站点/服务、命令及提示，再“确认部署”。计划过期或配置变更后需重新生成。

群晖使用 DSM 管理员密码认证，暂不支持两步验证。替换证书保留原描述、服务关联和默认状态；新增证书后的服务分配需在 DSM 中设置。

提交后由后台执行，关闭弹窗不会取消任务。“部署记录”按目标展示状态、阶段、步骤和验证结果。文件写入、平台更新与 HTTPS 实际生效分别记录，需按验证结果判断是否生效。

- 执行中可请求“取消后续步骤”，已完成的远端改动不会自动撤回。
- “待核对”任务先核对远端；人工核对后可填写实际结果并解除阻塞，该操作不代表部署成功。
- 失败或取消后可重新生成计划。支持恢复文件的执行器可从原任务预览并恢复备份文件；恢复不会自动执行刷新、重启或其他后置命令，需另行核对服务状态。

## 证书计划任务

在“计划任务”新建计划，选择证书账号、完整单域名、自动 DNS 验证方式、1～20 个部署目标、首次执行时间和按小时/天/月的周期，页面时间按上海时区显示。计划账号需启用证书与 DNS 用途，同账号同域名只能启用一条申请计划。计划目标目前支持雷池、群晖和 Linux 文件部署；后来新增的目标不会自动加入已有计划。

- 后台按轮次申请证书、等待签发、部署到所选目标并处理清理；浏览器可以关闭，但后端服务需保持运行。
- 可启用签发后的验证记录清理；如开启“吊销删除老证书”，仅在全部目标成功后处理计划范围内的旧证书：未过期的先吊销并确认，再删除；已过期的直接删除。
- “立即执行”提交一轮申请与部署，不改变原周期锚点。通过运行历史核对申请、各目标部署和清理结果，按页面提供的恢复或人工核对入口处理异常。
- 阿里云计划自动选取可用免费实例，不会自动购买；没有可用实例时需先在云控制台领取。
- 停用计划后不再发起后续周期，已提交的部署仍需在“部署记录”中管理。

## 邮件与证书到期提醒

管理员进入“邮件管理”，先在“邮箱设置”填写 SMTP 服务器、发送邮箱及授权码/密码，按服务商要求选择 SSL/TLS 或 STARTTLS，保存后检测连接，再发送测试邮件并到收件箱核对。已保存授权码留空时保留原值。

- “发件记录”可发送邮件、搜索历史并查看详情。记录仅包含本系统提交的邮件；“已提交邮件服务器”表示 SMTP 受理，不代表最终送达或已读。“结果待核验”时先检查原记录或收件箱，避免重复发送。
- 在“到期提醒”启用规则并设置提前天数、重复间隔和收件人。默认提前 30 天、每 1 天重复；间隔为 0 时仅首次提醒。提醒依赖已配置且启用的 SMTP，以及最近同步到本地的证书有效期。
- 已产生且未解除的预警会在到期后继续提醒，直到原证书有效期更新至范围外、被撤销/删除或手动忽略。同域名的另一张新证书不会自动解除原证书预警；忽略不能撤回已提交的邮件。

## 配置导入导出

管理员进入“配置导入导出”，可在 Web、容器与桌面实例之间迁移云账号、部署目标、证书周期计划、SMTP 和到期提醒规则。

1. 导出 JSON 配置。文件包含云密钥、密码、Token、SSH 私钥等明文凭据，请在可信环境保存和传递。
2. 在目标实例选择本系统导出的 JSON（最大 5 MiB，最多 1000 条配置），选择“仅新增”或“按名称更新”，先预览冲突和变更再确认导入。
3. 预览有效期为 15 分钟；更换文件、导入方式或现有配置变化后需重新预览。相关任务运行时不能更新其配置。
4. 导入项均保持停用，自动同步关闭。核对账号用途、同步域名/证书并测试部署目标后，再逐项启用。

配置迁移不包含登录用户、证书文件、运行历史、预警状态及原实例密钥环，不能代替数据库与密钥的完整备份。导入结果待核验时先检查当前配置和审计记录，再重新进入页面操作。

## 首页仪表盘

仪表盘统计启用云账号、托管域名、证书总数、已签发数量、30 天内到期数量和已过期数量，并展示平台分布、状态分布及近期到期证书。点击统计卡片可以进入对应列表，点击刷新可重新读取数据。

## 用户与权限

- 管理员：配置云账号、同步资源、管理证书和 DNS、部署目标与任务、周期计划、邮件、配置迁移、用户及审计日志。
- 只读用户：查看仪表盘、域名和证书；写操作及证书下载需要管理员权限。
- 右上角头像菜单提供修改密码、主题设置和退出登录。修改密码需要输入旧密码、新密码和确认密码。
- “审计日志”可按操作人、操作等条件查询配置、DNS、证书及系统管理操作记录，用于核对执行结果。

## 主题与显示

从右上角头像菜单打开“主题设置”，可调整布局、整体风格、主题色、固定头部和菜单显示。开启抽屉标题旁的“跟随系统”即可使用自动模式，系统切换浅色/深色时页面随之更新；点击原有浅色或深色卡片可退出自动模式。主题模式保存在当前浏览器，刷新后恢复，并即时应用到菜单、头部和内容区域。

列表默认使用紧凑小号表格。每个列表可以独立设置表格密度和列显示，设置保存到浏览器本地存储；聚焦列表时可使用键盘左右方向键翻页。右上角文档按钮打开本页，语言按钮切换简体中文和 English。

## 桌面客户端

桌面客户端内置本地服务与数据库，首次使用同样先创建管理员，证书、DNS、部署和计划任务的操作与 Web 版一致。“桌面设置与备份”提供关闭行为、登录自启、日志位置和加密备份恢复。

- 关闭主窗口默认保留托盘后台服务；使用“完全退出”才停止后台。关机、注销、睡眠或完全退出期间不会执行计划，重新启动或唤醒后继续恢复未完成阶段，并按周期规则补跑。
- 使用加密 `.sslbak` 备份保留业务数据和密钥。恢复前退出原客户端，避免两台电脑同时执行同一份备份中的计划；配置 JSON 用于迁移设置，不能代替完整备份。

## 常见问题

### 阿里云 MissingParameter

请确认已选择阿里云联系人，并在云控制台确认免费证书实例的规格；实例 ID 必须来自“待申请”且未使用的基础版实例。检查 AccessKey 是否拥有 CAS V2 申请权限。

### 同步数量不完整

检查账号的 DNS 或证书用途开关、分页权限和网络连接，然后再次点击同步。平台只在获得可信的全量快照后更新本地数据。

### 没有可选的部署目标或计划账号

先启用部署目标并完成连接测试；文件映射目标还需与证书主域名匹配。计划账号必须同时启用证书和 DNS 用途，托管 DNS 验证前需同步该账号域名。

### 证书部署后服务仍显示旧证书

在部署记录查看具体目标的验证结果和步骤，确认文件路径、关联站点/服务及刷新或重启命令。文件写入成功不等于 HTTPS 已生效；结果待核对时先使用“核对远端”，再按实际服务状态处理。

### 到期提醒没有发送

检查 SMTP 是否已配置并启用、连接与测试邮件是否成功、提醒规则和收件人是否已启用，以及证书最近同步的有效期。再查看到期预警及发件记录，核对重复提醒间隔和最近一次发送结果。
